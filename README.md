# 근거 기반 자료 검증기 v1.4 (무료형)

URL, 본문, 특정 주장 문장을 입력하면 관련 팩트체크 문서와 웹 근거를 찾아 `반박됨 / 지지됨 / 일부 사실·맥락 필요 / 지지 근거 다수 / 반박 근거 다수 / 근거 충돌 / 관련 근거 확인 / 근거 부족 / 의견·해석`으로 정리하는 Cloudflare Workers 프로젝트입니다.

## v1.4 핵심 변경
- 긴 원문 전체를 그대로 검색하지 않고 핵심 키워드로 여러 검색어를 만들어 검색 성공률을 높였습니다.
- Google News RSS 검색 결과의 제목·발행처·관련성을 함께 평가합니다.
- 팩트체크 문서에서는 `ClaimReview` 구조화 데이터를 먼저 찾고, 없으면 결론·판정 문장 주변에서 명시적 판정 표현을 확인합니다. Google은 `ClaimReview` 마크업을 Search에서는 단계적으로 축소하고 있지만 Fact Check Explorer에서는 계속 지원한다고 안내합니다.
- 팩트체크 결과가 하나도 없다는 이유만으로 곧바로 `판단 보류`가 나오지 않습니다. 관련 문서 본문에서 주장과 맞거나 충돌하는 문장 근거를 추가로 검사합니다.
- 복수 독립 출처의 일치 여부를 따로 계산해 `지지 근거 다수 / 반박 근거 다수`로 구분합니다.
- 팩트체크 문서의 결론을 앞부분 8문장에만 의존하지 않고 문서 전반에서 탐색합니다.
- 칼럼·사설의 평가/전망 문장은 `의견·해석`으로 분류하고 참·거짓 판정을 강제로 만들지 않습니다.
- 숫자·날짜가 동일하고 공식/통계/발표 문맥인 문장은 명시적 `사실` 표현이 없어도 근거 신호로 사용할 수 있습니다.
- 로컬/사설 IP 주소 입력을 차단해 URL 읽기 기능의 위험한 내부 접근을 막았습니다.
- GitHub 배포본에는 테스트 파일을 넣지 않습니다.

## 무료 구성
- OpenAI API를 사용하지 않습니다.
- 기본 검색은 Google News RSS를 사용합니다.
- Google Fact Check Tools API는 선택 기능입니다.
- URL 읽기가 막힌 경우 Jina Reader를 보조 경로로 사용합니다.

## 중요
이 도구의 자동 결과는 검색·팩트체크 근거를 정리한 참고용 결과입니다. 검색 결과가 같은 주장을 반복하는 것만으로 사실이 증명되는 것은 아니므로, 최종 확인에서는 원문과 1차 자료를 직접 대조해야 합니다.

## 테스트
Node.js 18+에서:

```bash
node tests/worker-smoke.mjs
node --check public/app.js
node --check src/index.js
```

같은 단위의 핵심 숫자·날짜가 근거 문서와 다르면 단순 지지로 처리하지 않습니다. 예: 33개↔10개, 1위↔2위, 10월 2일↔10월 1일.
