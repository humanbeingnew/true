# 근거 기반 자료 검증기 v1.2 (무료형)

URL, 본문, 특정 주장 문장을 입력해 관련 자료와 팩트체크 신호를 함께 확인하는 Cloudflare Workers 프로젝트입니다.

## v1.2에서 해결한 핵심 문제
- 이전 버전은 Google Fact Check API 키가 없을 때 거의 모든 결과가 `판단 보류`로 끝나는 구조였습니다.
- 이제 Google News RSS의 팩트체크 검색 결과에서 명시적인 판정 표현을 찾고, 상위 팩트체크 기사 원문도 추가 확인합니다.
- 부정 표현을 먼저 검사해 `사실 아님`을 `사실`로 잘못 분류하지 않도록 했습니다.
- 팩트체크 판정을 직접 찾지 못해도 여러 독립 출처가 있으면 `추가 확인 필요`로 올려 근거를 보여줍니다.
- RSS의 `<source url>`을 읽어 실제 발행처 도메인을 표시하도록 개선했습니다.
- `favicon.svg`, URL 실패 처리, 3가지 입력 방식은 v1.1 수정 내용을 유지합니다.

## 판정 흐름
1. 기존 Google Fact Check Tools API 결과가 있으면 우선 사용합니다.
2. API 키가 없으면 Google News RSS에서 `팩트체크`, 일반 주장, `사실/거짓/반박` 검색을 실행합니다.
3. 팩트체크 기사 후보를 최대 2개까지 읽어 명시적 판정 표현을 찾습니다.
4. 명시적 판정이 없으면 여러 출처의 존재를 근거로 `추가 확인 필요`를 표시합니다.
5. 정말 관련 자료가 거의 없을 때만 `판단 보류`를 표시합니다.

## 무료 구성
- OpenAI API를 사용하지 않습니다.
- 기본 검색은 Google News RSS를 사용합니다.
- Google Fact Check Tools API는 선택 기능입니다.
- URL 읽기가 막힌 경우 Jina Reader를 보조 경로로 사용합니다.

## 중요
이 프로그램은 자동 사실확인 보조 도구입니다. 검색 결과의 존재만으로 사실 여부를 확정하지 않으며, 최종 판단은 원문과 근거 자료를 직접 대조해야 합니다.
