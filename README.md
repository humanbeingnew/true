# 관련 자료 찾기 v2.0

이 프로젝트는 입력한 뉴스·칼럼·본문·주제와 관련된 자료를 찾아주는 무료형 Cloudflare Workers 웹앱입니다.

## 프로그램의 목적
참/거짓을 자동 판정하지 않습니다. 대신 다음 자료를 묶어서 보여줍니다.
- 관련 뉴스
- 관련 칼럼·오피니언
- 공식·1차 자료
- 관련 팩트체크 자료

## 3가지 시작 방법
1. 자료 주소로 찾기
2. 본문으로 찾기
3. 주제·문장으로 찾기

## 검색 방식
- Google News RSS를 기본 검색으로 사용합니다.
- 입력 내용에서 핵심 키워드를 추출한 뒤 뉴스/칼럼/공식/팩트체크용 검색어를 따로 만듭니다.
- URL 읽기는 직접 요청 후 실패하면 Jina Reader를 보조 경로로 사용합니다.
- 검색 결과는 제목, 출처, 날짜, 연관 이유와 함께 원문 링크를 제공합니다.

## 배포
GitHub에는 `public/`, `src/`, `wrangler.toml`, `README.md`만 올립니다. 테스트 파일은 별도 압축본에 있습니다.

## 주의
검색 결과는 관련성을 기준으로 수집한 자료 목록입니다. 관련성이 높다는 뜻이 진실임을 의미하지 않습니다.
