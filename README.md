# 관련 자료 찾기 v2.1

입력한 뉴스·칼럼·본문·주제에서 **관련 자료를 찾아 모아주는** Cloudflare Workers 웹앱입니다.

참/거짓을 자동 판정하지 않습니다. 검색 결과를 원문 링크와 함께 보여 주어 사용자가 직접 비교할 수 있게 하는 것이 목적입니다.

## 3가지 시작 방법
1. 자료 주소로 찾기
2. 본문으로 찾기
3. 주제·문장으로 찾기

## 검색 구조
- Google News RSS
- Bing News RSS
- Bing Web RSS
- 여러 개의 짧은 검색어를 만들어 교차 검색
- 뉴스 / 칼럼·오피니언 / 공식·1차 자료 / 팩트체크 자료로 분류
- 제목뿐 아니라 RSS 요약(description)도 연관도 계산에 사용
- 원문 URL을 읽을 때 직접 요청이 실패하면 Jina Reader를 보조 경로로 사용
- Jina Reader 요청은 원본 URL을 URL-인코딩하지 않고 그대로 전달
- 입력 URL 자체는 관련 결과에서 제외

## 배포
GitHub에는 `public/`, `src/`, `wrangler.toml`, `README.md`만 올리면 됩니다.
테스트 코드는 별도 압축본에 분리했습니다.

## 무료형 설계 메모
Google News 검색 RSS는 검색어별 피드를 만들 수 있고, Bing News도 RSS 형식의 검색 결과를 제공하는 방식이 널리 사용됩니다. 이 프로젝트는 별도의 유료 검색 API 키 없이 RSS 기반으로 검색합니다.

## 주의
검색 결과는 **관련 자료 후보**입니다. 결과가 관련 있다는 사실이 원문의 참·거짓을 의미하지 않습니다. 원문을 직접 열어 비교하세요.
